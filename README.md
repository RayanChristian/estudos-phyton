# My Python Journey 

Bem-vindo ao meu repositório de estudos de Python! Este espaço foi criado com o objetivo de centralizar, organizar e registrar toda a minha evolução na linguagem.

Aqui você encontrará códigos, anotações, pequenos projetos e exercícios práticos que desenvolvo no meu cotidiano de aprendizado.

---

## De onde vem o conteúdo?

Os arquivos deste repositório refletem minhas experiências reais de aprendizado em diferentes frentes:

*   **Faculdade:** Projetos acadêmicos, algoritmos, estruturas de dados e trabalhos avaliativos.
*   **Cursos Livres:** Exercícios e desafios práticos de cursos de especialização presenciais ou online.
*   **Trabalho:** Automações, tratamento de planilhas, melhorias de processos e scripts úteis para demandas profissionais no dia a dia.
*   **Projetos Pessoais:** Aplicações práticas para testar novas bibliotecas e criar soluções reais.
*   **Atividades do Dia a Dia:** Scripts rápidos, automações cotidianas e rascunhos de lógica de programação.
